# 모바일 주차·문서 UI 보완 — 2026-10-02

`poc` `3222659`. [백엔드 0.7.0 변경](../back/parking-document-update-2026-10-02.md)에 맞춰 주차 용도와 상시/지정 시간 표시 선택·요일·기간·미리보기를 추가했다. 일시중지 버튼을 제거하고 기존 기록을 유지한다.

TXT/MD/CSV UTF-8 원문 10MB를 IndexedDB에 보관하며 목록에는 메타데이터, 상세에는 용량·원문 보관 상태·제한된 미리보기·원문 다운로드 버튼을 제공한다. 기존 문서도 읽는다.

PoC 테스트 56개·구문 검사·CSS 빌드 통과. 320×568, 375×667 모바일의 가로 넘침과 시간 입력 배치를 확인했다. 실제 10MB 파일 저장·새로고침 후 다시 열기를 확인했으며 브라우저 다운로드 완료 이벤트는 확인하지 못했다.

실제 서버 문서 API 연결·전체 화면 연동·운영 배포·Hermes/GPU·기기 푸시는 후속이다. UI/UX 전달용 Word 문서는 변경하지 않았다.
