# PoC 기능 재점검과 보완

2026-11-03 기준, PoC의 `src/app-experience.js`와 화면별 사용 흐름을 backend 0.9 코드에 다시 대조했다. API 존재 여부와 별도로 실패·재시도·사용자 전환·결과 유지까지 확인했다. PoC 화면 자체는 변경하지 않았다.

파일 변경은 master 작업 폴더에만 반영했다. 추가 migration은 `0015_chat_attachments`이며 기존 대화의 첨부 목록은 빈 배열로 채운다. 배포 시 API와 worker를 같은 버전으로 교체한다. [통합 API·배포 계약](poc-backend-0.9.md)을 함께 따른다.

## 별도로 남아 있는 범위

자동 검사는 임시 PostgreSQL과 제어된 외부 HTTP 응답으로 수행한다. 새 이미지의 실제 기동, Kubernetes 권한·스토리지·네트워크 정책, GPU 모델 출력, 실제 결제와 시세 계정, 모바일 녹음·Push는 실제 환경 검증이 필요하다. 웹 결제 외 App Store/Play Store 결제, HWP 원본 편집, OCR, 실시간 체결 스트림은 현재 계약에 포함되지 않는다. 국내 주식의 완료된 1분봉은 아래 후속 대조에서 추가했으며 범위는 [시세 계약](billing-market.md)을 따른다. 구현하지 않은 기능에 가짜 성공 응답을 추가하지 않았다.

문서·음성·사용자 기능의 화면 연결은 향후 실제 프론트엔드에서 수행한다. 이번 작업은 PoC의 로컬 상태를 새 API로 교체하지 않는다.

## 추가 보완 후 검증

backend 전체 **455개 테스트가 통과**했다. 실제 PostgreSQL migration upgrade/downgrade, 사용자 소유권·권한 전환·재시도·취소·문서 실제 읽기를 포함한다. Ruff 검사·포맷과 OpenAPI 생성 파일 일치 검사도 통과했다. 외부 라이브러리의 deprecation 경고 2건이 있으며 테스트 실패는 없다. 테스트 DB는 종료·삭제했다.

같은 변경을 세 영역으로 나눠 독립 리뷰했다. 결제/권한/개인 환경, 채팅/예약/트랜잭션, 공용 gateway/프로세스 경계를 각각 검토하고 재현 가능한 문제를 수정했다. 문서 처리 수정도 다른 리뷰어에게 재검토를 받았다.

핵심 결제·동시성·gateway 회귀 테스트는 수정 전 실패를 확인했다. 최종 전체 검증은 backend **466개 통과**, Hermes **85개 통과·1개 건너뜀**이다. 건너뛴 검사는 테스트 환경에 Trafilatura가 없는 본문 추출 항목이며 공용 gateway 회귀 검사는 통과했다. Ruff·포맷·OpenAPI 일치·diff 검사도 통과했다. 임시 PostgreSQL은 종료·삭제했다. 운영 결제·실제 클러스터 배포·commit·push는 수행하지 않았다.

## 후속 독립 검토: 결제 확인과 결과 보존

다시 세 서브 에이전트가 인증·회원·문서, 실행 큐·예약·알림, 개인 런타임·공용 gateway·외부 데이터 경계를 나눠 검토했다. 결제 복구는 별도로 검토하고 다른 리뷰어에게 수정 내용을 재확인받았다.

| 우선순위 | 재현 조건과 영향 | 수정·회귀 검사 |
|---|---|---|
| P1 | 승인 응답 유실 후 주문 조회가 401·403으로 거부되면 기존 주문을 결제 실패로 확정하고 새 결제를 허용 | 조회 실패는 확인 대기로 유지. 연결 복구 시 원래 주문 조회만으로 확정하고 중복 청구 차단. 실제 청구 거절은 기존 실패 처리 유지. `test_billing.py` |
| P2 | 관리자 회원 목록과 등급 필터가 만료·취소된 유료 계정을 저장된 Pro 등급으로 표시 | SQL에서 유효 등급을 계산해 응답·필터·페이지 나눔에 함께 적용. 유효한 유료 권한과 관리자 부여 권한 보존. `test_membership.py` |
| P2 | 같은 주제의 기사 재검색 성공 후 AI 요약만 실패하면 이전 성공 요약이 사라짐 | 이전 기사·요약·수집 시각을 함께 보존하고 stale 표시. 다음 정상 갱신에서는 새 출처와 요약으로 교체. 수동·예약 경로 모두 검증. `test_news_summary.py` |

뉴스 예약 실행의 완료 답변도 이전 브리핑을 유지한 경우와 기사만 수집한 경우를 구분한다. 정상 요약에서는 기존 답변과 완료 상태를 유지한다.

후속 검토 전체 검증: backend **483개 통과**, Hermes **85개 통과·1개 건너뜀**. 건너뛴 Trafilatura 의존 검사와 외부 라이브러리 deprecation 경고 2건은 이전과 같다. Ruff 검사·포맷, OpenAPI 일치, runtime manifest, diff 검사 통과. 임시 PostgreSQL은 종료·삭제했으며 새 migration·API 스키마 변경·PoC/plan 수정·실제 제공자 호출·commit·push는 없다.

주차 조회는 기존 주차 행을 읽으며 추가 저장하지 않는다. 같은 요청 키의 재조회와 대화 목록에서 다시 열었을 때도 동일한 참조가 유지된다. 예약 주가의 `/v1/market/snapshot`은 최신 스냅샷이므로 이후 갱신될 수 있다. 과거 회차의 가격·시각·제공자는 기존 실행 결과에서 별도로 확인할 수 있다. 취소·실행 권한 만료·종목 변경으로 게시가 거부되면 완료 참조도 생성하지 않는다.

참조 수정은 새로 완료되는 작업에 적용한다. 이미 저장된 과거 이벤트와 같은 요청 키의 재생 결과를 재작성하는 migration은 추가하지 않았다.

다른 담당 흐름에서는 새 서버 누락을 확정하지 못했다. 대조표의 대화 삭제·복원 항목은 실제 PoC에 버튼이 없는데 구현 완료로 적혀 있어 정정했다. 서버의 대화 DELETE는 별도 확장이고 복원 API는 없다. 주차 표시 값과 사용자 기능 표시 구간처럼 PoC 내부 계산이 서버 계약과 다른 부분은 [화면별 대조표](poc-parity-map-0.9.md)에 명시했다. Swagger·Scalar 소개의 KIS 설명에도 이미 구현된 국내 당일 1분봉을 반영했다.
