# PoC 화면과 서버 기능 대조표

2026-11-03, PoC 브랜치 `8fa4fe4`의 실제 화면과 이벤트 처리 코드를 기준으로 확인했다. 세 서브 에이전트가 화면별 입력·저장·조회·재시도를 나눠 점검했고, 브라우저에서도 대시보드·일정·대화·기능·마이와 상세 화면을 열어 확인했다. 화면을 새 API에 연결한 통합 시험은 아니다. 구현은 master 작업 폴더에만 반영하며 PoC의 코드와 사용자 데이터는 바꾸지 않는다.

아래 행의 소스 위치는 **PoC 브랜치**의 `src/app-experience.js`다. `experience.mjs`는 채팅 예시와 로컬 실행을 정의한다. API 경로는 모두 `/v1` 아래에 있다.

## 새 연결의 데이터 계약

보관함과 대시보드의 `recent_records`는 같은 항목 타입을 사용한다. `icon`은 메모·문서·실행 결과의 아이콘이며 실행 결과에는 해당 기능의 현재 아이콘을 쓴다. 문서의 `filename`, `size_bytes`와 실행 결과의 `item_count`, `completed_count`를 반환한다. 해당 종류가 아닌 필드는 `null`이다. 텍스트 문서 크기는 UTF-8 바이트 수, 업로드 파일 크기는 실제 저장 바이트 수다. 목록에서는 본문을 160자까지만 반환하고 원문과 체크 항목은 상세 주소에서 읽는다.

메모의 `updated_at`은 마지막 내용 저장 시각이다. 삭제·복원은 `revision`과 `deleted_at`에 반영하고 이 시각을 유지한다. 오래된 메모를 되돌린 것만으로 오늘 정리에 포함하거나 최신 기록으로 올리지 않는다. 실제 편집해 저장하면 오늘 정리에 포함된다. 이 변경 전 이미 삭제·복원으로 바뀐 과거 시각은 이전 내용 저장 이력이 없어 복원하지 않는다.

대화 목록은 `updated_at` 대신 `last_activity_at`으로 날짜 그룹을 만든다. `updated_at`은 제목 변경 같은 관리 작업에도 바뀐다. 대화가 비어 있으면 생성 시각을 활동 시각으로 반환하고, 메시지가 있으면 마지막 사용자 요청 시각을 사용한다. `last_message`는 마지막 요청의 답변이 있으면 답변, 아직 없으면 사용자 메시지다. 초안은 PoC처럼 클라이언트에서 관리하며 서버 메시지로 저장하지 않는다.

알림 진행률은 `clamp((target_at - now) / (target_at - started_at), 0, 1)`로 계산할 수 있다. `created_at`은 처음 만든 시각이므로 재시작 때 바꾸지 않는다. `0016_reminder_started_at`은 기존 알림의 시작 시각을 `created_at`으로 채운다. 과거 재시작의 정확한 시각은 기존 데이터만으로 복원할 수 없으며, 새 버전에서 재시작한 뒤부터 새 기준이 보존된다.

주가 설정에서 `schedule`을 생략하면 기존 예약을 유지하고, 명시적으로 `null`을 보내면 해제한다. 예약 객체를 보내면 기본 주가 기능을 만들거나 수정한다. 기존 기능의 예약을 바꾸려면 읽기 응답의 `feature_revision`이 필요하다. `revision`은 관심 종목 버전, `feature_revision`은 예약 기능 버전이다. 충돌하면 종목만 부분적으로 저장하지 않는다.

## 클라이언트 작업과 실제 환경 검증

달력 그리드·겹침 미리보기, 날짜/시간 다이얼, 화면 전환·카드 확장, 로컬 폼 초안, 반응형 배치와 그래프 렌더링은 프론트엔드 책임이다. 가상 시계와 개발자용 실패 상태 체험은 운영 API가 재현할 기능이 아니다.

일부 PoC 내부 값은 API에 그대로 전달하지 않는다. 오프라인 주차 예시의 시간 없는 `always`는 ‘기능 탭에서 조회’라는 의미여서 서버의 `manual`로 연결한다. 서버의 명시적 `always`는 새 위치를 저장할 때까지 대시보드에 표시하는 별도 선택이다. 사용자 기능의 현재 카드 표시도 PoC의 두 계산 경로가 다르므로 서버가 반환한 `show_from/show_until`을 사용한다. 서버 계약은 실행 시각부터 90분이며 뉴스·주가는 별도 표시 구간이 있다. 사용자 기능의 카드 아이콘은 `resource_id`로 기능 목록·상세의 `icon`과 연결할 수 있다.

대화 삭제는 서버가 별도로 제공하는 기능이다. 현재 PoC에는 대화 삭제·복원 버튼이 없고 서버에도 대화 복원 API는 없다. 메모·일정·문서 등의 되돌리기와 혼동하지 않는다.

현재 계약은 웹 Toss 결제와 Web Push다. App Store/Play Store 구매 검증, 네이티브 Push, 즉시 환불 요청 API는 포함하지 않는다. 기사별 원문 전체를 읽는 AI 요약, OCR, HWP 원본 편집도 구현됐다고 표시하지 않는다. 실제 결제·시세 계정, HTTPS Push, 모바일 마이크, Harbor 이미지·k3s RBAC·PVC·CNI·콜드 스타트 지연은 해당 환경에서 확인해야 한다.

새로 구현한 경로의 회귀 검사와 전체 테스트 결과는 [재점검 기록](poc-coverage-review-0.9.md)에 남긴다.
