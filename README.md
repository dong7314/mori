# mori — 일상을 가볍게 하는 작은 비서

`poc` 브랜치의 UI/UX 프로토타입입니다. HTML, vanilla JavaScript, SCSS만 사용합니다. 실제 제품은 사용자가 React 반응형 웹으로 구현하고, 이후 모바일 앱의 WebView와 네이티브 기능으로 확장합니다. 이 PoC는 화면과 상호작용을 검토하기 위한 참고 구현입니다.

## 실행

Node.js 22 이상을 권장합니다. 컴파일된 CSS가 포함되어 있어 화면을 보는 데 패키지 설치는 필요 없습니다.

```sh
npm start
```

<http://127.0.0.1:4173>에서 열립니다. 포트를 바꾸려면 `PORT=4174 npm start`를 사용합니다. 서버는 로컬 컴퓨터에서만 접근하도록 구성했습니다.

스타일을 수정할 때:

```sh
npm ci
npm run styles:watch
```

한 번만 빌드하거나 문법을 확인할 때:

```sh
npm run build
npm run check
```

## 둘러보기

1. **오늘**에서 주차 위치를 저장합니다. 마지막 기록 카드와 아침 위젯 미리보기에 반영됩니다.
2. **모리에게 말하기**에서 녹음·전사 흐름을 체험하고, 예시 전사 내용을 수정해 저장합니다. 실제 마이크는 켜지지 않습니다.
3. **일정 추가**에서 약속을 등록하고 **캘린더**에서 날짜를 선택해 조회·수정·삭제합니다.
4. **여행 계획**에서 여행지와 기간을 선택해 예시 결과를 확인합니다. CSV 표 파일을 내려받거나 브라우저 인쇄로 PDF를 저장할 수 있습니다.
5. **확인이 필요한 일**에서 미리 준비한 제주 일정을 승인하면 체험 캘린더에 일정 3개가 추가됩니다. 재확인으로 중복 생성하지 않습니다.
6. **내 기록**에서 생활 메모를 남기고 **자동으로**에서 반복 설정과 시간을 변경합니다.
7. **시간대 미리보기**의 아침·오후·저녁을 바꿔 대시보드 인사와 위젯 표시를 비교합니다.

우측 상단 **내 설정 → 체험 데이터를 처음으로 되돌리기**로 초기 예시를 복원할 수 있습니다. 입력한 체험 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다. 채팅 메시지는 새로고침하면 초기화됩니다.

## 구현 범위

| 항목 | 현재 동작 |
| --- | --- |
| 대시보드·캘린더·기록·반복 설정 | 실제 화면 이동과 로컬 상태 저장 |
| 주차 위치·일정 | 입력·조회·수정·삭제 및 해당 화면 반영 |
| 생활 메모 | 입력·조회 및 기록 화면 반영 |
| 음성 입력 | 녹음→처리→편집→저장의 시뮬레이션. STT 미연결 |
| 채팅 | 저장한 주차·오늘 일정을 조회하는 정해진 응답. LLM 미연결 |
| 여행 | 입력한 여행지·기간을 반영한 고정 예시. 실제 검색·추천 미수행 |
| 표 다운로드 | UTF-8 BOM을 포함한 CSV 파일. Excel에서 열 수 있으며 `.xlsx`는 아님 |
| PDF 저장 | 여행 결과를 인쇄용 스타일로 출력. 브라우저 인쇄창에서 PDF 선택 필요 |
| 승인 | 브라우저 안의 예시 캘린더에만 추가. 외부 캘린더 미연결 |
| 자동화·개인화 | 학습 후 화면과 설정 저장 체험. 실제 학습·예약 실행 미연결 |
| 휴대폰 위젯 | 시간대별 화면 미리보기. 실제 OS 위젯·푸시·알람 미구현 |

인앱 브라우저 등에서 인쇄창을 지원하지 않으면 Chrome/Safari에서 같은 URL을 열어 이용합니다. 서버에서 생성·배포하는 PDF 파일은 후속 백엔드 범위입니다. 날짜는 브라우저의 현지 시간을 기준으로 하며, 처음 실행하거나 초기화한 날을 기준으로 예시 일정을 구성합니다.

## 화면 구성

- 차분한 녹색과 밝은 배경, 큰 실행 버튼, 카드 중심 홈
- 데스크톱 상단 메뉴, 모바일 하단 메뉴와 입력 바텀시트
- 키보드 포커스, 네이티브 `dialog`, 폼 라벨, 상태 알림, 모션 감소 설정 대응
- 외부 이미지·웹폰트·런타임 라이브러리 없이 SVG 캐릭터와 아이콘 사용

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 뼈대, 공통 내비게이션, SVG 아이콘 |
| `src/app.js` | 화면 템플릿, 이벤트 처리, 체험 데이터 |
| `styles/main.scss` | 색상·레이아웃·반응형·인쇄 스타일 원본 |
| `styles/main.css` | 브라우저에서 읽는 컴파일 결과 |
| `scripts/serve.mjs` | 로컬 미리보기 서버 |

## 확인한 범위와 다음 검토

2026-09-16 로컬 브라우저에서 주차 저장 및 새로고침 후 유지, 일정 등록과 날짜별 조회, 승인 후 캘린더 반영, 생활 메모, 반복 켜기/끄기·시간 변경, 음성 입력 시뮬레이션, 저장한 주차의 채팅 조회, 여행 결과와 CSV 다운로드를 확인했습니다. 데스크톱 및 모바일 폭에서 화면을 검토했고 JavaScript 문법 검사와 SCSS 빌드가 통과했습니다.

실제 기기 접근성, 부모님 등 대상 사용자 사용성, React·앱 컨테이너·네이티브 브리지, 백엔드·인증·STT·LLM 연동은 후속 검증 범위입니다. 모호한 일정의 추가 질문, 실패·오프라인 복구, 카드 고정·숨기기도 이 PoC 이후에 검토합니다. 제품 구현 계획은 `plan` 브랜치의 문서를 기준으로 관리합니다.
