# mori — 모바일 앱 화면 PoC

`poc` 브랜치의 HTML·JavaScript·SCSS 프로토타입입니다. **제품은 휴대폰 앱을 우선하고 태블릿까지 지원**하며, 독립 웹/데스크톱 웹 서비스는 현재 계획에 없습니다. 이 URL은 앱에 들어갈 화면을 브라우저로 미리 보는 용도입니다. 실제 앱 컨테이너·OS 위젯·알림·마이크·백엔드는 연결되지 않았습니다.

## 실행

Node.js 22 이상을 권장합니다. 미리보기에는 빌드된 CSS가 포함되어 있어 설치 없이 실행할 수 있습니다.

```sh
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)에서 열립니다. SCSS를 수정할 때는 `npm ci` 후 `npm run build` 또는 `npm run styles:watch`를 실행합니다. `npm run check`와 `npm test`로 문법과 기존 모델 동작을 확인할 수 있습니다.

## 앱 화면 구조

- **오늘:** 다음 일정 한 가지, 바로 부탁할 주차·코스피·Excel 작업, 저장된 기억을 순서대로 보여줍니다.
- **대화:** 같은 대화에서 글·음성 예시를 전환하고 작업 결과를 카드로 확인합니다. 파일 첨부는 이름만 저장합니다.
- **캘린더:** 날짜별 일정을 보고 추가·수정합니다.
- **보관함:** 주차 위치·생활 기록·결과물을 다시 찾고, 배운 방식과 반복 작업을 관리합니다.
- **입력:** 휴대폰에서는 하단 탭 위의 글·음성 진입점, 짧은 가로 화면과 태블릿 가로에서는 측면 탐색을 사용합니다.

모바일 세로·가로와 태블릿 세로·가로를 고려했습니다. 브라우저 확인 크기는 390×844, 844×390, 768×1024, 1024×768입니다. 실제 iPhone/iPad의 안전 영역·키보드·회전 동작은 앱 컨테이너에서 검증해야 합니다.

## 대표 흐름 체험

1. **주차:** 오늘 화면에서 주차 위치를 저장하거나 대화에 `지하 3층 B16에 주차했어`를 보냅니다. 최신 위치가 기억 목록에 반영됩니다.
2. **정기 브리핑:** 코스피 브리핑을 누르고 대화에 `오전 9시 30분마다 코스피 근황을 알려줘`를 보냅니다. 예시 작업 카드와 켜기/중지 설정이 생깁니다. 실제 시세 검색·예약 실행·PDF·알림 발송은 하지 않습니다.
3. **Excel 정리:** Excel 파일 정리를 누른 뒤 파일을 첨부하고 요청을 보냅니다. 파일 **이름과 요청**을 담은 예시 카드가 나타납니다. 파일 내용은 읽거나 업로드하지 않으며, 실제 `.xlsx` 결과는 만들지 않습니다. 예시 CSV는 다운로드할 수 있습니다.
4. **일정:** 캘린더에서 직접 추가하거나 대화로 약속을 등록합니다. 날짜·시간이 모호하면 필요한 내용을 되묻습니다.
5. **음성:** 하단 마이크로 문장을 선택·수정하고 전송 흐름을 체험합니다. 실제 녹음과 STT는 연결되지 않았습니다.

주차·일정·대화·예시 반복 설정은 이 브라우저의 `localStorage`에 저장됩니다. 설정의 초기화 버튼으로 체험 데이터를 되돌릴 수 있습니다. PDF는 브라우저 인쇄 창에서 저장하는 예시이고, 검색·파일 분석·OS 위젯·푸시·Hermes는 아직 미연결입니다. 무료 비서·위젯 약 3개와 유료 무제한 등록 정책도 이 PoC에서는 화면·서버로 구현하지 않았습니다.

## 디자인과 구현 경계

첫 화면에서 행동을 세 가지로 줄이고, 큰 제목·짧은 설명·일관된 행 목록으로 정보를 정리했습니다. 휴대폰 하단 탭은 화면 이동, 글·음성 입력창은 작업 시작에 사용합니다. 안전 영역과 세로/가로 레이아웃은 [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 및 [Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars) 지침을 참고했습니다. 한 화면의 밀도와 쉬운 문구는 [토스 디자인 원칙](https://toss.tech/article/value-first-cost-later)과 [당근 SEED](https://seed-design.io/)를, 대화와 음성의 연결은 [ChatGPT Voice 안내](https://help.openai.com/en/articles/20001274)를 참고했습니다. 특정 앱의 화면·브랜드 자산을 복제한 것은 아닙니다.

`src/app.js`는 화면과 예시 상호작용, `styles/_app.scss`는 앱 우선 레이아웃, `styles/main.css`는 빌드 결과입니다. 기존 요청 해석·대화 저장·반복 모델과 테스트는 `src/*.mjs`, `tests/*.test.mjs`에 있습니다.
