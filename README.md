# mori — 일상을 가볍게 하는 작은 비서

`poc` 브랜치의 HTML·vanilla JavaScript·SCSS 화면 프로토타입입니다. 실제 제품의 React 반응형 웹 → 모바일 WebView 확장 방향은 유지합니다.

## 실행

Node.js 22 이상을 권장합니다. 컴파일된 CSS가 포함되어 있어 미리보기에는 패키지 설치가 필요 없습니다.

```sh
npm start
```

<http://127.0.0.1:4173>에서 열립니다. 포트 변경은 `PORT=4174 npm start`로 지정합니다. 로컬 컴퓨터에서만 접근하도록 구성했습니다.

```sh
npm ci                  # 스타일 개발 의존성 설치
npm run styles:watch    # SCSS 수정 시 CSS 갱신
npm run build           # CSS 한 번 빌드
npm run check           # JavaScript 문법 확인
npm test                # 시간·요일별 위젯 선택, 대화 해석 경계 검증
```

## 이번 PoC의 중심 흐름

**필요한 기억을 먼저 보여주는 대시보드 → 말하거나 입력하는 대화 → 결과 카드 → 저장한 규칙으로 다음 순간을 챙김**

대시보드 첫 위젯은 현재 요일·시간과 기억한 규칙으로 자동 선택합니다. 화면의 시간대 선택은 검토용 시뮬레이터이며, 위젯을 수동으로 추가하는 설정이 아닙니다. 기본값은 실제 현재 시간입니다.

- 평일 07:00–09:00: 출근길에 필요한 최신 주차 위치. 위치와 기록 시각을 함께 표시합니다.
- 그 밖의 시간: 오늘 남은 가장 가까운 약속을 표시합니다. 지난 약속은 제외합니다.
- 저녁에 오늘 일정이 끝났다면: 내일 첫 약속을 표시합니다.
- 주말·일정 없는 시간: 평일 주차 규칙을 적용하지 않고 쉬어가는 안내를 표시합니다.

화면을 열어둔 동안 30초마다, 또는 화면으로 돌아올 때 첫 위젯을 갱신합니다. 위젯 갱신 때문에 작성 중인 메시지를 지우지 않습니다. `기억한 시간`을 선택하면 대화로 변경한 규칙의 시작 시각을 미리 볼 수 있습니다.

## 직접 체험하기

1. 첫 화면의 시간대에서 **평일 · 출근길 07:30**을 선택합니다. 주차 위치가 첫 카드로 나옵니다. 오후·주말과 비교해 보세요.
2. 홈 입력창 또는 **모리와 대화** 메뉴에서 `지하 2층 C18에 주차했어`를 보냅니다. 사용자 말풍선 아래에 주차 결과 카드가 나타나고 첫 위젯의 최신 위치도 바뀝니다.
3. **마이크**를 누르고 체험 문장을 선택하거나 수정한 뒤 **말하기 종료 · 대화로 보내기**를 누릅니다. 음성 문장은 `음성으로 보냄` 말풍선으로 전달됩니다. 주차 전용 입력 폼으로 이동하지 않습니다.
4. `내일 6시 30분에 민수와 약속을 등록해 줘`를 보냅니다. 오전·오후를 추가로 확인한 뒤 대화 안에 일정 저장 결과가 나옵니다. 캘린더에서도 조회·수정·삭제할 수 있습니다.
5. `부산 2박 3일 여행 계획을 짜줘`를 말하거나 입력합니다. 같은 대화 안에서 여행 계획, PDF 미리보기, Excel용 CSV, 캘린더에 담기를 이어갈 수 있습니다.
6. `이번 달 지출 정리용 엑셀 양식을 만들어줘`, `회의 내용을 PDF 문서로 정리해 줘`처럼 여행 이외의 문서 작업도 대화로 요청합니다. **파일 첨부**에서는 PDF·Excel 등의 파일 이름을 붙이는 흐름을 체험할 수 있습니다.
7. `평일 아침 8시부터 9시까지 주차 위치를 보여줘`를 보냅니다. 표시 방식이 저장되고 **자동으로 → 모리가 기억한 방식**과 **시간대 체험 → 기억한 시간**에서 확인할 수 있습니다. 중지·재개도 제공합니다.

대화·주차·일정·메모·문서 결과·표시 규칙은 이 브라우저의 `localStorage`에 저장되고 새로고침 후에도 유지됩니다. 설정에서 체험 데이터를 초기 예시로 되돌릴 수 있습니다. 파일 내용은 읽거나 업로드하지 않으며 파일 이름만 대화에 남습니다.

## 실제 동작과 예시의 경계

| 항목 | 현재 동작 |
| --- | --- |
| 첫 위젯 | 현재 시간·요일·약속·저장된 주차 규칙에 따라 자동 선택 |
| 기억한 표시 방식 | 자연어 `prompt`, 요일, 시작·종료 시각, 출처를 함께 저장하고 대화로 변경 |
| 자동 학습 | 반복 습관을 이미 배운 예시 규칙으로 시작. 실제 반복 패턴 학습·Hermes 스킬 생성은 미연결 |
| 채팅 | 독립 화면과 홈 입력창, 메시지 저장, 요청별 결과 카드. 정규식 기반 예시 처리이며 LLM 미연결 |
| 음성 | 문장 선택·편집으로 녹음 종료→메시지 전송을 시뮬레이션. 실제 마이크·STT 미연결 |
| 일정 | 오늘·내일·모레·요일·날짜와 숫자 시각을 해석하는 제한된 예시. 모호한 오전·오후 및 날짜는 추가 질문 |
| 여행 | 2~5일 예시 계획. 실제 검색·장소·가격 확인은 수행하지 않음 |
| PDF·Excel | 대화에서 요청한 내용을 담은 예시 문서와 양식. PDF는 인쇄 창에서 저장, 표는 Excel에서 열 수 있는 CSV이며 `.xlsx`는 아님 |
| 파일 첨부 | 최대 3개 파일 이름 표시. 실제 PDF·Excel 분석·변환·외부 업로드 미구현 |
| 휴대폰 | 이번 첫 위젯은 앱 안의 대시보드 카드. 실제 OS 홈 화면 위젯·푸시·알람은 후속 모바일 범위 |

자유로운 한국어 이해는 제한되어 있어 위 예시 문장 중심으로 검토합니다. 일정의 추가 질문 도중에는 답하거나 `취소`로 마무리합니다. 표시 규칙의 종료 시각을 생략하면 시작부터 2시간 동안 표시하는 예시 정책을 사용하며, 저장된 문장에서 적용 구간을 확인할 수 있습니다.

인앱 브라우저가 인쇄창을 지원하지 않으면 Chrome/Safari에서 같은 URL을 열어 PDF를 저장합니다. 서버가 생성하는 실제 PDF·Excel 및 첨부 파일 분석은 백엔드 연결 후 구현합니다.

## 파일과 연동 경계

| 파일 | 역할 |
| --- | --- |
| `index.html` | 공통 내비게이션과 대화 진입점, 아이콘 |
| `src/app.js` | 대시보드·대화·캘린더·기록 UI, 로컬 저장, 결과 카드 |
| `src/assistant-model.mjs` | 요일·시간별 첫 위젯 선택, 제한된 요청 해석과 표시 규칙 변경 |
| `styles/main.scss` | 기존 공통 스타일 |
| `styles/_conversation.scss` | 자동 위젯·홈 입력창·대화·문서 카드·모바일 스타일 |
| `styles/main.css` | 브라우저가 읽는 컴파일 결과 |
| `tests/assistant-model.test.mjs` | 평일/주말·시간 경계·규칙 중지·최신 주차·모호한 약속 등의 검증 |
| `scripts/serve.mjs` | 로컬 미리보기 서버 |

실제 연동에서는 Hermes가 사용자의 반복 의도와 표시용 프롬프트를 관리하고, 서버가 검증한 표시 규칙·최신 데이터·갱신 시각을 내려주는 방향입니다. 프론트는 대화 메시지와 작업 결과, 첫 카드의 표시를 맡습니다. PoC의 정규식 해석기와 `localStorage`를 운영용 에이전트·예약 실행·권한 시스템으로 취급하지 않습니다.

## 검증

로컬 브라우저에서 음성 종료 후 사용자 메시지와 결과 카드, 주차 저장과 첫 위젯 반영, 대화로 표시 규칙 변경, 오전·오후 추가 질문 후 일정 저장, 여행과 일반 문서 카드, PDF 미리보기, CSV 다운로드와 요청 내용 보존, 여행 승인 후 일정 반영을 확인했습니다. 모바일·데스크톱 반응형 화면과 새로고침 후 대화 복원을 확인했습니다. 실제 대상 사용자 사용성, 물리 기기 녹음·키보드·알림·위젯, Hermes 연동은 후속 검증 범위입니다.
