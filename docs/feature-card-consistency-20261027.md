# 기능 카드 표시 통일 · 2026-10-27

기본 기능 카드 오른쪽 위의 장식 화살표를 제거했다. 내 기능의 행 목록을 기본 기능과 같은 `feature-grid` / `feature-tile` 구조로 바꾸고 제목·설명·상태·오른쪽 그림 영역을 맞췄다. ‘새 기능 만들기’도 같은 크기의 카드로 표시하며 점선 테두리로 추가 동작을 구분한다. 내 기능의 예약 시간, 최근 결과, 사용 중·중지·초안 표시는 보존한다.

내 기능과 추가 카드에도 기본 기능과 동일한 카드별 진입 모션, 눌림·호버·키보드 포커스 처리를 적용했다. 기존 행 목록용 묶음 애니메이션은 해당 화면에서 사용하지 않는다.

## 검증

ego-browser의 실제 localhost:5173 페이지에서 모든 기능·기본 기능·내 기능 필터를 전환해 계산된 배치와 텍스트 넘침을 확인했다.

| 화면 폭 | 기본 기능 / 내 기능 / 추가 카드 | 결과 |
| --- | --- | --- |
| 320px | 너비 284px, 높이 124px, 패딩 15px 16px, 모서리 22px | 모두 동일, 가로 넘침 없음 |
| 390px | 너비 342px, 높이 약 124.8px, 패딩 15px 18px, 모서리 22px | 모두 동일, 가로 넘침 없음 |
| 768px | 너비 약 343.8px, 높이 190px, 패딩 22px, 모서리 23px | 모두 동일한 2열, 가로 넘침 없음 |
| 1249px | 너비 536px, 높이 198px, 패딩 24px, 모서리 23px | 모두 동일한 2열, 가로 넘침 없음 |

모든 카드의 우측 상단 화살표가 없고, 내 기능 상세 화면 열기 및 뒤로 돌아가기도 확인했다. `npm run build`, `npm run check`, 전체 테스트 323개, `git diff --check`를 통과했다.

화면 이미지의 시각 검증은 미완료다. ego-browser의 캡처 요청이 시간 초과됐고, 인앱 브라우저 대체 확인은 origin 접근 정책에서 거절됐다. 이후 추가 브라우저 접근을 시도하지 않았다. 위 결과는 실제 페이지의 DOM·계산된 배치·조작 결과이며, 스크린샷을 관찰한 결과로 해석하지 않는다.

## 후속 조정

사용자 요청에 따라 목록의 ‘새 기능 만들기’ 카드를 제거했다. 기능 추가는 헤더의 + 버튼으로 통일하고, 내 기능이 없을 때도 해당 버튼을 안내한다. 추가 카드에만 사용하던 점선 스타일도 제거했다.

사용자 스크린샷에서 내 기능의 단일 아이콘이 기본 기능의 그림 영역 크기를 상속해 과도하게 커진 점을 확인했다. 내 기능에만 48×48px 배경과 22px 아이콘을 적용하고 테두리를 제거했다. 모바일·태블릿의 그림 크기 규칙이 이 값을 덮어쓰지 않도록 선택자 범위를 명시했다. 카드 전체의 크기·텍스트·상태·전환 효과는 유지한다. 이번 크기 조정은 사용자 이미지와 CSS를 기준으로 했으며 SCSS 빌드와 diff 검사를 통과했다.
