# 모바일·태블릿 UI 재구성

2026-10-20. 기존 기능과 저장 데이터를 유지하면서 모바일 화면 구조와 스타일을 다시 구성했다. 기존 파스텔 톤을 유지하고 Liquid Glass는 떠 있는 조작부에 적용해 달라는 피드백을 반영했다.

이 구현은 승인된 디자인의 기준선이다. **태블릿 배치, 카드 오른쪽 시각 요소, 채팅 안에서 이어지는 음성 UX와 애니메이션은 미완료**이며 [필수 후속 수정 사항](poc-ui-followups.md)에 별도로 기록했다.

## 화면과 표현

- 오늘: 짧은 날짜·인사, 고정된 주차/일정/메모/대화 버튼, 실제 저장 위치와 기록 시각을 표시하는 정보 카드, 오늘 일정·최근 대화·기록. 기존 큰 캐러셀을 세로 정보 카드로 바꾸어 내용을 바로 읽는다.
- 일정: 월/주/일 전환, 날짜 이동과 일정 추가·수정, 주간 목록과 일간 타임라인. 일 보기에도 정확한 시작·종료 시각을 표시한다.
- 대화: 검색과 날짜별 대화, 새 대화·초안·고정·이름 변경. 메시지 중심의 전체 높이 대화 화면과 하단 입력창을 사용한다.
- 기능·마이: 같은 행·타일·버튼 체계로 기본 기능, 반복 부탁, 계정·테마·요금제에 접근한다.
- 음성: 인식한 말을 수정한 뒤 현재 대화 초안에 담는 기존 흐름을 유지한다. 녹음을 누르기 전에는 마이크 권한을 요청하지 않는다.

세이지·라벤더·크림·회청색을 아이콘과 정보 맥락에 사용한다. 밝은 콘텐츠 표면 위에 이중의 낮은 그림자를 두고, 하단 입력창·탭 바·닫기 버튼에는 반투명 소재와 테두리 하이라이트, 흐림을 적용했다. 본문은 불투명한 표면에서 읽는다. 다크 테마는 같은 색 계열의 어두운 표면과 대비되는 글자·아이콘을 사용한다.

Apple 기기는 시스템 글꼴과 Apple SD Gothic Neo, 다른 기기는 로컬 Pretendard를 사용한다. 제목 28–30px, 섹션 18px, 주요 내용 15–19px, 입력 16px을 기준으로 rem을 사용한다. 긴 이름은 줄바꿈하며, 제어 버튼은 글자가 확대되어도 접근할 수 있게 배치한다.

화면·시트·새 메시지의 모션을 유지하고 정기적인 시계 갱신에는 진입 모션을 재생하지 않는다. 움직임 줄이기와 투명도 줄이기 환경설정을 지원한다.

## 참고한 공식 자료

- [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials): 콘텐츠와 떠 있는 제어부의 소재 구분.
- [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography): 역할에 따른 글자 위계와 시스템 글꼴.
- [Toss ListRow](https://tossmini-docs.toss.im/tds-mobile/components/ListRow/list-row-overview/): 아이콘·내용·보조 정보의 일관된 정렬.
- [토스](https://apps.apple.com/kr/app/%ED%86%A0%EC%8A%A4/id839333328): 생활 정보와 다음 행동의 짧은 흐름.
- [네이버 앱](https://apps.apple.com/kr/app/%EB%84%A4%EC%9D%B4%EB%B2%84-naver/id393499958): 입력 진입점과 음성 도구, 생활 기능으로 이어지는 안정적인 탐색 구조.
- [ChatGPT 모바일](https://chatgpt.com/download/): 메시지 중심 화면, 최소한의 헤더와 떠 있는 조작부.
- [Muse / Allume](https://allume.com/): 콘텐츠가 중심이 되는 차분한 작업 공간. Muse는 현재 Allume으로 이름이 변경되었다.

## 확인 범위

- `npm run build`, `npm run check` 확인. 최신 `origin/poc`의 계정·폼 초안·음성 전사·시트 상태 개선을 통합한 회귀 테스트 102개가 통과했다.
- 320px 휴대폰에서 다섯 탭의 가로 넘침 없음.
- 같은 화면에서 글자 200% 확대 후 다섯 탭, 기존 대화 헤더·입력창, 시간 지정 주차 폼의 가로 넘침 없음. 확대 확인용 CSS는 제거하고 다시 빌드했다.
- 390×844 모바일의 오늘·일정·기능·대화·음성과 768×1024 태블릿 다섯 탭을 직접 확인했다. 태블릿의 정보 카드 너비는 338px이며 두 열로 표시된다. 568×320 가로 화면의 시간 범위 메뉴는 내부 스크롤로 모든 선택에 접근한다.

기존 계정 API, 로컬 기록, 파일 원문 보관, 대화 초안과 기능 참조를 유지한다. 뉴스·주가·로컬 알림·반복 부탁은 기존 체험 범위이며 실제 AI·시세·푸시·결제 연결로 표시하지 않는다.

`/preview.html`은 실제 앱을 모바일·태블릿 iframe으로 표시한다. 각 프레임의 로컬 체험 기록·테마 저장 키를 분리해 동시 조작이 다른 프레임이나 실제 앱 기록을 덮어쓰지 않게 했다.
