## 후속 개선 적용

1. **자동 갱신 보존:** 계정 조회·예약 작업·분 단위 갱신·응답 완료는 현재 화면의 변경된 노드와 속성만 갱신한다. 검색 입력·캐럿·키보드 포커스·가로 스크롤·달력 격자·진행 중 애니메이션을 유지한다. 한글 조합 중에는 본문 갱신을 확정 입력 뒤로 미룬다. 동일한 CSS 변수는 공백 등 직렬화 차이만으로 다시 쓰지 않으며, 런타임 스크롤바도 보존한다.
2. **내 기능 예약 설정:** 시간을 입력하면 보이는 반복 선택도 즉시 ‘매일’로 맞추고 안내한다. ‘필요할 때’를 선택하면 시간을 지운다. 예약 실행은 시간을 필수로 표시하고, 선택한 시간·반복이 유효하지 않으면 저장을 막고 해당 필드에 안내한다. 저장 시 조용히 다른 실행 방식으로 바꾸지 않는다. 초안 복원·예시 입력·미리보기·오류 해제에도 같은 상태를 반영한다.
3. **달력 리사이즈:** 화면 크기 변경 시 표시 영역 높이와 내부 격자 이동의 CSS 전환만 완료해 새 행 높이와 선택 주를 맞춘다. 푸터 선택 배경도 새 위치·너비로 보정하고, 본문 진입·필터 전환은 끊거나 재생하지 않는다. 명시적인 월·주·일 변경 시 기존 420ms 접힘·펼침은 유지한다.
4. **검색 전환:** 입력을 120ms 단위로 묶고, 조합 중 결과 교체를 보류한다. 검색어 지우기는 즉시 반영한다. 실제 결과가 같은 경우 모션을 생략하고, 달라질 때도 투명도 .85에서 가볍게 표시한다. 전환 중 연속 변경은 현재 밝기·위치에서 이어진다. 분리된 입력·취소된 콜백은 늦게 목록을 덮어쓰지 않는다.
5. **진행 중 일정:** 시작·종료 시각으로 ‘지금 진행 중 / 다음 일정 / 오늘 남은 일정 없음’을 구분한다. 자정을 넘는 약속은 실제 종료를 표시하며, 전날부터 이어진 약속도 포함한다. 일정 화면을 열어 둔 동안 분 경계에서 요약을 조용히 갱신한다.

기존 푸터의 순차 진입, 기능 카드 전환, 달력 접힘·펼침 정책은 유지한다. 파일 가져오기 대기 표시와 토스트 만료 조정은 추가 제안으로 남아 있으며 이번 5개 항목의 적용 범위에 포함하지 않았다.

검증: `npm run check`, `npm run build`, `git diff --check`와 전체 자동 테스트 **322개**를 통과했다. 실제 앱 함수와 위임된 이벤트 처리에서 자동 갱신 보류·검색 결과 동일 시 모션 생략·시간/반복 연동과 저장 거부·진행 중/자정 넘김 요약·리사이즈 전용 처리 경로를 확인했다. DOM 단위 검사에서는 포커스·캐럿·리스너·달력 격자·가로 스크롤·스크롤바 보존을 검증했다.

실제 브라우저 검증은 저장된 localhost 접근 제한으로 미완료다. 별도 브라우저·직접 자동화로 우회하지 않았으며, 회전 시 잘림·IME 사용감·프레임 연속성은 실제 화면에서 추가 확인이 필요하다.

## 실제 화면 후속 검증 완료 · 2026-10-24

위 문단은 권한 변경 전 기록이다. 사용자가 접근 설정을 변경한 뒤 ego-browser에서 localhost:5173의 푸터·달력·기능 필터를 직접 검증했다. 인라인 스타일을 차단하는 CSP 때문에 달력 접힘 값이 적용되지 않던 문제를 `data-*` 속성과 외부 CSS로 수정했다. 빠른 왕복에서 높이와 날짜 이동이 어긋나던 문제도 공유 CSS 진행률로 해결했다.

320·390·768px과 넓은 화면, 반응형 경계 변경, 빠른 재선택, 라이트·다크, 동작 줄이기, 조합 입력 중 검색 보존을 확인했다. 최종 달력 왕복에서 날짜 DOM 35개·투명도 1을 유지했고 선택 날짜 잘림·가로 넘침·잔여 전환 레이어·브라우저 오류는 없었다. 최종 자동 검사는 **323개 통과**이며 빌드·구문·diff 검사도 통과했다. 자세한 재현 조건·증거·검증 한계는 [모션 레퍼런스와 실제 화면 검증 기록](motion-reference-and-verification-20261024.md#권한-변경-후-실제-화면-검증--2026-10-24)에 정리했다.
