# 화면 연결감과 조작감 보완

기준: `poc`의 `0d68e8d`. 기존 파스텔·세이지 유체 모션과 화면 탐색 구조 위에서 이동의 연결감과 입력 화면의 안정성을 다듬었다.

## 바뀐 동작

- 하단 탭의 버튼과 유리 선택 표시를 DOM에 유지한다. 빠른 재선택은 화면에 그려진 위치에서 이어지고, 정기 갱신도 이동 중인 표시를 이전 목적지로 되돌리지 않는다. 글자는 11px로 통일하고 선택 표면에 가벼운 하이라이트와 그림자를 적용했다.
- 탭 변경은 본문 전체가 260ms 동안 함께 정착한다. 카드마다 늦게 나타나는 전환과 스크롤 중의 반복 진입 효과를 제거했다. 연속 전환에서는 현재 투명도·위치를 이어 사용하며 아이콘의 과도한 크기 변화도 줄였다.
- 상세 내부 이동에서 이전 제목과 새 제목이 본문의 앞·뒤 방향에 맞춰 280ms 동안 교차한다. 복제 제목은 ID·포커스를 갖지 않으며 완료·중단·닫기·동작 줄이기에 정리한다. 긴 제목은 한 줄로 표시해 헤더와 저장 버튼의 위치를 유지한다.
- 폼의 선택 목록은 실제 차지하는 높이를 열기 260ms·닫기 210ms로 전환한다. 아래 필드가 먼저 튄 뒤 목록만 페이드되던 동작을 바꿨다. 빠른 반전은 중간 높이를 이어가며 키보드 포커스와 Escape 동작을 유지한다.
- 크기 전환 중 스크롤 표시는 이미 관리 중인 영역의 위치·길이만 계산한다. 화면 전체의 스크롤 대상 탐색은 DOM·스타일·뷰포트가 바뀔 때 수행해 매 프레임의 불필요한 탐색을 줄였다.
- 시간·날짜·카운트다운 숫자에는 같은 자릿수 폭을 사용한다.

## 검증

- `npm run build`, `npm run check`, `npm test`: 통과. 총 **217개**, 이 중 새 회귀 검증은 빠른 탭 반전·배경 갱신·본문 투명도 연속성·선택창 높이 반전·제목 레이어 정리를 포함한다.
- 브라우저에서 320×640, 390×844, 390×480, 768×1024의 가로 넘침과 스크롤 여백 없음 확인.
- 보관함 → 새 메모 → 뒤로 이동, 선택창 열기·닫기·즉시 재열기·Escape 후 원래 필드 복귀, 완료 후 잔여 제목 없음 확인.
- 태블릿 라이트·다크, 음성 패널 열기·닫기, 미리보기 체험의 입력 완료와 초안 유지 확인. 음성 패널의 열기 전·중간·후에 입력줄은 `top=893, bottom=937, height=44px`로 동일했다.
- 테마와 체험 초안을 확인 전 상태로 복원했다. 실제 마이크 녹음은 사용하지 않았으며, 동작 줄이기는 자동 테스트로 확인했다.
- 캡처: `output/continuity-polish/`.

소재 표현은 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)의 내비게이션·컨트롤 중심 구성을 참고했다. 구체적인 이동 거리·시간과 제목 전환은 모리 화면에 맞춘 구현이다.

## 보관함 누름 상태와 음성 입력 수정 · 2026-10-22

- 목록의 음수 inset 가상 요소가 버튼 배경을 상속해 한 번 더 칠하던 구조를 제거했다. 실제 버튼을 그룹의 끝까지 넓히고 콘텐츠에만 여백을 둔다. 구분선은 별도 1px 선이며, 첫·끝 행의 배경과 포커스 표시는 그룹 모서리 안에서 잘린다. 보관함뿐 아니라 설정·안내·테마 선택에도 같은 규칙을 쓴다.
- 행 아이콘은 정해진 타일 안에서 가운데 정렬한다. 페이지 헤더의 아이콘 버튼도 44px 원형 터치 영역과 도형의 중심을 맞췄다.
- 음성 입력을 열 때 환영 화면을 `display:none`으로 없애고 본문 높이를 바꾸던 규칙을 제거했다. 입력 표면은 대화 위에서 펼쳐지고, 본문과 스크롤 위치는 그대로 유지된다. 환영 화면의 장식 구슬만 페이드해 활성 구슬이 중복되지 않게 했다.
- 클립으로 펼치는 표면에 `backdrop-filter`를 함께 적용하면 내용보다 큰 최종 배경이 먼저 나타나는 중간 프레임이 있었다. 이 표면은 반투명 배경·안쪽 하이라이트·그림자로 표현한다. 헤더와 하단 내비게이션의 블러는 유지한다.
- 음성 패널 안의 ‘키보드로 입력 / 내용 수정’ 버튼을 삭제했다. 대기·완료 상태에서 기존 메시지 입력창을 누르면 패널을 접고 같은 초안을 이어 쓴다. 녹음 중에는 읽기 전용 상태를 유지하고, 완료한 음성은 초안에 한 번만 합친다.
- 별도 복구 입력란은 음성 인식 오류로 남은 문장이 있을 때만 표시한다. 음성 미지원 상태에서는 기존 메시지 입력창을 안내한다. 여러 줄 입력으로 입력줄이 커지면 본문 아래 여백도 맞춰 마지막 메시지를 가리지 않는다.

### 실제 확인

- 모바일 보관함 버튼을 1.6초 누른 채 측정: 행 350×100.28px, 아이콘 타일 34×34px, 도형 19×19px. 누르기 전후 좌표·크기·타일 색상 동일. 헤더 아이콘 중심도 버튼 중심과 일치.
- 390×844 기존 대화에서 음성 열기 전·중·후 본문 `top=67, height=777`, `scrollTop=65`, 입력줄 `top=777, bottom=821` 유지.
- 768×1024에서 표면이 펼쳐지는 초기 클립 프레임부터 입력줄 `top=893, bottom=937`과 환영 화면 위치 유지. 배경이 먼저 크게 나타나던 프레임도 재확인했다.
- 음성 체험의 완료 → 초안 합치기 → 입력창 터치 → 이어 쓰기, 녹음 중 입력 보호, 체험 취소 후 기존 초안 유지 확인. 실제 녹음·메시지 전송은 수행하지 않았다.
- 320×640의 음성 패널과 44px 마이크·전송 버튼에 가로 넘침 없음. 여러 줄 입력에서 마지막 메시지는 입력 표면 위에 남는다. 태블릿 다크·테마 선택 목록 확인 후 원래 라이트와 초안을 복원했다.
- `npm run build`, `npm run check`, `npm test` 통과: **217개**. 새 CSS 합성 수정 후에도 빌드 완료. 캡처는 `output/interaction-fixes/`.

## 음성 시작 버튼과 예시 펼침 보완

- ‘말하기 시작’은 옅은 세이지 캡슐과 40px 원형 마이크를 조합한 204×52px 버튼으로 바꿨다. 눌림은 배경·그림자만 변하고 크기와 도형 중심은 유지된다. 녹음 중 정지 도형, 인식 중 진행 표시, 완료 후 이어서 녹음 상태를 같은 컨트롤 안에서 갱신한다. 중간 인식 결과마다 버튼 DOM을 새로 만들지 않는다.
- ‘이렇게 말해 보세요’는 `aria-expanded`·`aria-controls`를 갖는 버튼과 같은 패널 안의 예시 목록으로 구성했다. 열기 260ms·닫기 210ms 동안 목록 높이만 변한다. 전체 음성 패널을 복제하던 전환을 제거해 구슬·제목·버튼이 겹쳐 나타나지 않는다. 빠른 반전은 현재 높이에서 이어가고 동작 줄이기를 지원한다.
- 320×640에서 두 줄 예시가 입력창과 겹치지 않도록 짧은 화면의 여백을 조정했다. 마지막 예시 하단 561.64px, 입력줄 상단 575px이며 가로 넘침과 내부 스크롤 잘림이 없다.
- 브라우저에서 모바일·태블릿 펼침, 빠른 키보드 재선택, 예시의 초안 입력, 라이트·다크, 음성 체험의 녹음·인식·완료를 확인했다. 펼침 중 복제 패널 0개·실제 버튼 1개·대화 1개이고 입력줄은 태블릿 893px·모바일 777px에 유지된다. 체험 후 테마와 초안을 원래대로 복원했다. 실제 녹음·전송은 수행하지 않았다.
- `npm run build`, `npm run check`, `npm test` 통과: **219개**. 목록 높이 반전과 동작 줄이기 중 종료 회귀 검증 2개 추가. 캡처는 `output/voice-controls/`.

## 캘린더 정렬과 화면 보완

- 기존 호버는 45px 높이 셀 전체에 칠해졌고, 날짜 숫자는 아래 표시 점 때문에 중심보다 4.5px 위에 있었다. 호버·누름·선택·키보드 포커스를 같은 날짜 원에 적용하고 표시 점은 별도로 배치했다. 셀 전체는 투명하며 날짜를 누르거나 이동해도 원이 커지지 않는다.
- 기본 날짜 원은 36px, 셀 높이는 모바일 48px·태블릿 56px다. 320px 화면에서는 원이 약 33.4px로 줄어 같은 비율을 유지한다. 브라우저에서 모든 날짜의 중심 오차는 최대 0.008px 미만이었고 호버·누름 중 크기가 유지됐다.
- 연도와 월의 글자 위계를 나누고 오늘·이전·다음 버튼을 정돈했다. 이동 아이콘은 44px 원형 영역 중앙에 놓인다. 범위 요약은 더 간결하게, 선택 날짜와 일정 개수는 분명하게 표시한다. 주 보기의 날짜 그룹, 일 보기의 시간별 입력 영역과 일정 카드의 피드백도 통일했다.
- 기간 변경은 달력 표면과 헤더를 고정하고 날짜 격자만 방향에 맞춰 240ms 전환한다. 일 선택은 일정 본문만 220ms 전환한다. 월 안에서 주 경계를 넘는 이동도 감지하며 동작 줄이기를 존중한다. ‘오늘’ 실행 후에는 같은 버튼으로 포커스를 돌려준다.
- 브라우저에서 390×844·768×1024의 호버·누름, 방향키 선택, 월 이동·오늘 복귀, 실제 3개 일정 표시를 확인했다. 320×640에서는 월·주·일 보기의 가로 넘침 없음, 2026년 2월의 28일 표시, 라이트·다크를 확인하고 테마를 복원했다.
- `npm run build`, `npm run check`, `npm test` 통과: **221개**. 기간 전환 중 표면 고정과 주 경계·날짜 선택 분리 회귀 검증 2개 추가. 캡처는 `output/calendar-refinement/`.
