# 채팅·음성 입력의 빛과 전환

기준 브랜치: `poc`, 시작 커밋 `bdbb3a5`.

## 디자인 방향

기존 파스텔과 세이지 초록색을 유지한다. 초기 커밋 `2cf01fd`의 `styles/experience.scss`에 있던 `.voice-orb`를 기준으로, 비정형 그라데이션 레이어 세 개가 회전하는 유체형 모션을 채팅에 적용한다. 마이크는 밝은 세이지색, 전송·녹음 버튼은 진한 초록색으로 구분한다. Apple 로고나 Siri 에셋을 사용하지 않고 CSS로 그린다.

- [Apple의 새로운 Siri 앱](https://www.apple.com/newsroom/2026/06/apple-introduces-siri-ai-a-profoundly-more-capable-and-personal-assistant/): 간결한 대화 본문과 하단 입력부의 위계 참고.
- [Apple Intelligence의 Siri](https://www.apple.com/sg/newsroom/2025/03/apple-intelligence-features-are-now-available-in-singapore/): 활성 상태에서 화면 가장자리로 퍼지는 빛 참고.
- [ChatGPT 음성 모드](https://help.openai.com/en/articles/8400625-voice-mode-faq): 같은 대화 안에서 이어지는 음성·텍스트 입력 흐름 참고.
- [Muse / Allume](https://allume.com/): 차분한 여백과 콘텐츠 중심의 공간감 참고. 음성 기능을 구현했다는 의미는 아님.

## 반영한 동작

- 초기 유체형 애니메이션의 방사형 그라데이션을 유지하고 중앙 별 아이콘을 제거한다. 레이어마다 11초·15초·8초 주기로 회전하며 두 번째는 반대 방향으로 움직인다. 외곽 곡선의 변형, 좌우·상하 이동, 축별 크기 변화를 별도 주기로 겹쳐 더 크게 일렁이도록 한다. 듣기 단계는 회전 3초·일렁임 2.8초 주기로 빨라진다. 동작 줄이기 설정에서는 두 움직임 모두 정지한다.
- 입력창의 공통 `:focus-visible`이 textarea에 그리던 사각형 outline을 제거한다. 바깥 캡슐의 포커스 표시는 유지하고, 다른 버튼과 보조 입력창의 키보드 포커스는 보존한다.
- 입력창 위에 음성 패널이 펼쳐지고, 인식이 끝나면 완료 표시로 접힌다. 입력된 문장은 흐림이 걷히며 나타나고 입력창에 짧은 반사광이 남는다.
- 입력창 하단을 고정한 채 높이를 전환한다. 키보드 전환, 기존 초안, 인식 실패 시 수정, 4,000자 제한, 자동 전송하지 않는 기존 동작을 유지한다.
- 홈의 음성 진입 버튼도 같은 세이지색으로 연결한다. 전송 버튼은 활성 상태에서 진한 초록색과 흰 화살표, 비활성 상태에서는 옅은 초록색을 사용한다. 주요 아이콘 버튼은 모바일·태블릿 모두 44×44px, 아이콘은 18px로 맞춘다. 녹음·키보드는 동일한 높이와 너비, 8px 간격을 사용한다.
- 시스템의 동작 줄이기 설정에서는 유체 레이어·가장자리·문장 전환 애니메이션을 정지한다.

## 브라우저에서 체험

`npm start` 후 `/preview.html`에서 **음성 UI 체험**을 누르면 실제 모바일·태블릿 앱 프레임이 요청 → 듣기 → 부분 문장 → 인식 → 초안 입력 과정을 보여준다. 실제 녹음이 아니라는 표시를 노출하며 마이크나 네트워크 음성 인식을 사용하지 않는다. 예시 문장은 전송하지 않는다.

체험은 별도로 저장되는 미리보기 프레임에서만 동작한다. 일반 앱 창과 다른 출처의 메시지로 시작할 수 없다. 취소·닫기·재시작 후 이전 체험의 콜백이 초안을 바꾸지 못하도록 세션 번호를 확인한다.

실제 음성 입력은 기존 브라우저 SpeechRecognition을 계속 사용한다. 구체의 움직임은 녹음 단계의 표현이며 실제 음량을 측정한 파형은 아니다. 이번 브라우저 검증에서는 실제 마이크 권한을 허용하거나 사용자 음성을 녹음하지 않았다.

## 검증

- 모바일 320×640, 390×844 및 태블릿 768×1024에서 배치와 넘침 확인.
- 라이트·다크 화면, 음성 예시 입력, 기존 초안과의 병합, 입력 후 수정, 자동 전송하지 않는 동작 확인.
- 미리보기 양쪽 프레임의 듣기 애니메이션과 완료 후 입력창 내용 확인.
- 마우스·Tab 이동으로 채팅 입력창의 포커스를 재현하고 내부 outline이 표시되지 않는지 확인. 유체 레이어의 실제 회전, 11초·15초·8초 주기와 역방향 레이어 확인. 수정 캡처: `output/fluid-restored/`.
- `npm run build`, `npm run check`, `npm test`: 통과. 전체 144개 테스트에 체험의 취소·닫기·재시작·수동 완료 및 공통 스크롤 회귀 검증 포함.
- 최종 유체 모션 캡처: `output/fluid-swell/mobile.png`. 모바일·태블릿 및 상세·다이얼로그의 최종 화면은 `output/overlay-scrollbars/`에 기록했다. 실제 음성 인식의 정확도·마이크 하드웨어 동작은 별도 기기 확인 필요.
