# PoC 필수 후속 UI/UX 수정

2026-10-20 사용자 검토 결과. 현재 파스텔·버튼 그림자·글라스·타이포그래피 개선안을 `poc`의 기준으로 반영한다. 아래 항목은 아직 완료되지 않았으며 후속 작업에서 반드시 수정한다.

## 1. 태블릿 앱 배치 재설계 — 미완료

현재 모바일 콘텐츠를 두 열로 넓힌 배치에는 개선이 필요하다. 정보의 우선순위, 카드 크기·밀도·정렬, 여백과 하단 조작부의 위치를 태블릿에 맞게 다시 설계한다. 단순히 열 개수를 늘린 상태를 완성된 태블릿 UX로 취급하지 않는다.

완료 기준:

- 세로·가로 태블릿에서 오늘 정보와 바로 실행할 행동이 균형 있게 보인다.
- 카드·일정·기록 영역의 정렬과 크기, 읽는 순서가 자연스럽다.
- 모바일의 쉬운 사용 흐름과 파스텔·글라스 표현을 유지한다.
- 실제 태블릿 크기에서 다시 사용자 검토를 받는다.

## 2. ‘지금 챙길 것’ 카드 오른쪽 시각 요소 교체 — 미완료

현재 주차 카드의 P·자동차 모양 등 오른쪽 아이콘/일러스트는 완성도가 부족하다. 임시로 그린 듯한 형태를 교체하고, 카드 전체와 어울리는 선 굵기·곡률·비율·색감·그림자로 통일한다. 장식보다 정보 이해에 도움이 되도록 크기와 위치를 정한다.

완료 기준:

- 주차를 포함한 각 카드의 오른쪽 시각 요소를 일관된 품질로 정리한다.
- 작은 모바일 화면과 태블릿에서 모양이 어색하거나 흐려지지 않는다.
- 핵심 텍스트와 기록 시각의 가독성을 해치지 않는다.

## 3. 채팅과 음성 입력을 하나의 UX로 통합 — 미완료

현재 구현은 채팅 dialog 위에 별도의 음성 dialog가 열린다. 최종 목표는 **채팅창 안에서 마이크 UX가 펼쳐지고, 녹음 후 인식한 말이 채팅 입력창으로 자연스럽게 들어가는 흐름**이다. 현재의 별도 음성 화면을 최종 UX로 유지하지 않는다.

목표 흐름:

1. 마이크를 누르면 현재 채팅의 입력 영역에서 음성 입력 UI가 확장된다. 다른 화면에서 진입해도 같은 채팅 안에서 이어진다.
2. 녹음 시작·녹음 중·중지·인식 중 상태를 파형과 명확한 피드백으로 보여준다.
3. 녹음이 끝나면 음성 상태가 인식한 문장으로 전환되고, 그 문장이 채팅 입력창에 담기는 세련된 연결 애니메이션을 구현한다.
4. 사용자는 입력된 문장을 확인·수정한 뒤 직접 전송한다.
5. 취소·권한 거부·인식 실패도 채팅 문맥 안에서 복구할 수 있게 처리한다.

유지할 동작:

- 현재 대화와 기존 초안을 유지하며, 인식한 말을 현재 초안에 추가한다.
- 녹음 시작 전에는 마이크 권한을 요청하지 않는다.
- 글자 제한, 전송 중 중복 방지, 대화별 초안 저장을 유지한다.
- 키보드·안전 영역·글자 확대와 움직임 줄이기를 지원한다.
- 실제 STT 연동 범위와 브라우저 체험 범위를 정확하게 표시한다.
