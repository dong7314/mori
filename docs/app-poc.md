## 시나리오

| 시나리오 | 체험 방법 | 결과 |
| --- | --- | --- |

| 뉴스 | 하루 미리보기 브리핑 09:00 / 기능 뉴스 | 수집 중→완료, 기준 시각·예시 출처, 실패→재시도 |
| 주가 | 기능→관심 주가→종목/기간 선택 | 그래프·라벨·통화 변경, 예시 시세 |
| 메모 | 우산 챙기기 메모해줘 / 직접 제목만 입력 | 대시보드 기록과 같은 메모, 편집/삭제 |
| 스케줄 | 내일 오후 2시 디자인 미팅 일정 추가해줘 | 월/주/일과 같은 일정, 직접 CRUD |
| 알림 | 음성 예시 30분 뒤 알림→대화로 이어가기 | 현재 대화에서만 상세 자동 열기, 초 단위 카운트다운, +5분/취소 |
| 커스텀 | 가이드 마지막 예시→결과→지금 실행 | 정의·버전, 오늘 메모 체크리스트, 편집/중지/재개 |
| 시간 없는 기능 | 시간 없이 저장 후 실행 | 대시보드 기록과 정리에 결과 표시 |
| 문서 | 문서 정리→예시 또는 TXT/MD/CSV | 실제 내용 읽기, 번호 목록+원문 TXT 생성 및 다운로드 요청 |
| 대화 유지 | 텍스트→음성 예시→수정→전송 | 같은 대화에 추가, 검색, 새로고침 후 복원 |
| 마이 | 출근·최근 대화·움직임 설정 | 카드 시간/대시보드/애니메이션 반영 |

커스텀의 이름·설명·시간·참고 내용·작업은 선택적으로 입력합니다. 작업 없는 정의는 초안이며 실행을 비활성화합니다. 공통 상세 템플릿을 사용하고 임의 UI 코드를 생성하지 않습니다. 일반 인사는 기능을 만들지 않습니다.

## 실행 모델

- 하나의 로컬 상태를 화면/대화/결과에서 공유하며 `mori.experience.v6`에 보관합니다.
- 체험 시각은 실제 경과 시간에 따라 흐르고 미리보기로 이동합니다. 시간 이동은 기록을 지우지 않습니다.
- 알림은 목표 timestamp를 저장합니다. 다른 대화나 화면으로 이동한 뒤에는 상세를 자동으로 열지 않습니다.
- 예약은 날짜+시간으로 중복을 막고 평일/1회를 구분합니다. 앱이 닫힌 동안 실제 실행을 보장하지 않습니다. 재접속 시 당일 미실행 항목을 보정합니다.
- 응답 대기 중 대화를 바꿔도 원래 대화에 기록합니다. 초기화 후에는 이전 응답을 버립니다.
- 커스텀 실행은 오늘 저장한 메모 제목을 체크리스트로 만드는 예시입니다. 임의 작업의 실제 AI 실행은 연결 전입니다.
- 뉴스와 주가는 예시 표시를 유지합니다. 기사 상세 출처도 예시입니다.
- 실제 계정은 기존 BFF를 사용합니다. 최신 주차 GET은 `/api/parking/latest`, 저장은 `/api/parking`와 idempotency key입니다.

## 검증

- build/check/test 통과, 36개 테스트.
- 새 테스트: 일반 대화의 기능 미생성, 최신 주차와 카드 표시 간격/중지, 현재 카드, 알림 시각 유지, 메모/일정 요청, 커스텀 중복 방지/중지, 예약 중복 방지/뉴스 상태 전이.
- 브라우저: 주차→메모→음성 예시→알림을 같은 대화로 실행, +5분/취소 확인.
- 커스텀 생성/실행/중지/편집과 버전 변경, 새로고침 후 기록 유지 확인.
- 대화 및 직접 일정 저장, 주간/일간 전환 확인.
- 뉴스 실패/재수집/완료, 애플 USD와 주간 그래프 전환 확인.
- 실제 문서 내용/원문 결과 생성 및 다운로드 요청 확인. 인앱 브라우저의 다운로드 이벤트 대기가 시간 초과하여 OS 파일 저장 완료는 검증하지 못했습니다.
- 390×844 폰 세로, 844×390 폰 가로, 768×1024 태블릿 세로, 1024×768 태블릿 가로 확인. 페이지 가로 넘침 없음. 검증 중 콘솔 오류 없음.
- 작은 폰 기준으로 320×568 세로, 375×667 세로, 568×320 가로를 다시 확인. 5개 탭, 대화창, 음성 입력, 주차·뉴스·알림·문서·커스텀 상세, 하루 미리보기, 일정 입력, 요금제 선택에서 가로 넘침과 버튼 접근성을 확인했습니다.
- 320px 폭에서 하루 미리보기 카드의 글자 쪼개짐, 일정 날짜·시간 입력의 가로 넘침, 주차 지도와 위치 번호의 겹침, 요금제 카드 줄바꿈을 수정했습니다. 작은 폰 높이에서는 음성 전송 버튼이 보이게 조정했고, 가로 화면에는 음성 입력을 두 열로 배치했습니다.
- 대시보드 외 탭의 과도한 하단 빈 공간과 대화 목록 마스코트 잘림을 줄였습니다. 화면 갱신 시 현재 스크롤과 카드 위치를 보존합니다. 위 미리보기 이미지는 375×667 모바일 화면입니다.
- 실제 마이크 녹음, 소셜 실계정, GPU/Hermes, OS 푸시, Excel/PDF 처리는 이번 UI 검증 범위 밖입니다.
