# 달력 선택·탐색 개선 · 2026-10-27

연·월 옆의 오른쪽 꺾쇠는 상세 이동처럼 보여 날짜 선택 동작을 설명하지 못했다. 또 날짜·기간을 선택할 때 전체 화면 DOM을 교체하고 달력과 목록에 좌우·상하 이동을 재생했다.

연도와 월을 한 줄로 묶고, 아래 방향 표시·대화상자 접근성 속성을 가진 선택 버튼으로 변경했다. 오늘·이전·다음은 44px 조작 영역과 12px 모서리를 사용한다. 이전·다음 버튼의 접근성 이름은 월·주·일 모드의 실제 이동 단위에 맞춘다. 좁은 화면에서는 버튼 간격을 줄이고 조작 영역을 유지한다.

날짜·오늘·기간 이동·월 선택은 `selectScheduleDate()` 한 경로로 처리한다. 기존 `patchLiveView()`를 통해 달력 표면·날짜 버튼·목록 호스트·스크롤을 유지하며 바뀐 내용만 갱신한다. 목록은 위치·크기를 움직이지 않고 투명도 .9→1의 260ms 전환으로 선명해진다. 연속 선택은 현재 밝기에서 이어지고, 같은 날짜는 효과를 다시 시작하지 않는다. 주 보기의 같은 주 내 선택은 목록을 다시 표시하는 대신 선택 그룹의 색상만 부드럽게 바꾼다.

월·주·일의 기존 공유 진행률 접힘 동작은 유지한다. 모드 전환 중 목록에 추가로 적용하던 8px 이동은 제거하고 .94→1의 가벼운 선명도 변화만 적용한다. 날짜 제목·약속 수는 접근성 알림 영역으로 표시한다. 월 선택은 선택창이 닫힌 뒤 갱신하며 연·월 선택 버튼으로 포커스를 복원한다.

검증: 빌드·구문·diff 검사 통과. 자동 테스트 **329개** 통과. 실제 선택 함수와 월 선택 이벤트에서 부분 갱신·동일 날짜/주 처리·월말 보정·포커스 복원을 검사했다. 모션 검사에서 불필요한 이동 없음, 연속 밝기 보존, 푸터 탭 진입 효과 보존, 동작 줄이기 시 즉시 갱신을 확인했다.

브라우저 접근 거부가 해제됐다는 새 확인이 없어 실제 화면에 다시 접근하지 않았다. 시각적 배치·실기기 체감 검증은 미완료이며 자동 검사 통과를 해당 검증으로 간주하지 않는다.
