# 영역 안쪽에 겹치는 스크롤 표시

기본 스크롤바가 콘텐츠 폭을 차지하지 않도록 숨기고, 스크롤 영역 오른쪽 안쪽에 별도의 표시를 겹친다. 콘텐츠에 래퍼나 여백을 추가하지 않는다.

- 요소 이름을 나열하는 대신 실제 `overflow-y: auto/scroll/overlay` 영역을 자동으로 찾아 적용한다. 상세 페이지, dialog 자체와 내부 본문, 중첩된 목록·문서·입력 영역, 페이지 자체 스크롤을 함께 지원한다. 새 dialog나 콘텐츠가 추가되어도 별도 등록이 필요 없다.
- 평상시 3px, 마우스를 올리거나 드래그할 때 5px로 표시한다. 스크롤 후 800ms 뒤 사라지며, 짧은 콘텐츠에는 표시하지 않는다.
- 휠·터치·키보드·초점 이동은 브라우저의 기존 스크롤을 사용한다. 마우스로 표시를 잡아 끌거나 트랙을 눌러 이동할 수 있다. 터치 기기에서는 표시가 터치 조작을 가로채지 않는다.
- 중첩된 영역의 클리핑과 미리보기의 배율을 반영하고, 화면 크기·텍스트·동적 패널·인라인 overflow 스타일이 바뀌면 대상을 다시 찾고 위치와 길이를 계산한다. 상세 화면 전환과 다이얼로그 애니메이션 종료 후에도 갱신한다.
- 동작 줄이기 설정과 고대비 모드를 지원한다.

## 확인

- 390×800 채팅에서 음성 패널을 펼쳐 스크롤이 생기기 전후 콘텐츠 폭 390px, 중앙 195px, 스크롤바 여백 0px 유지.
- 채팅의 휠·표시 드래그, 대시보드의 PageDown, 일정 입력 시트의 휠 이동 확인.
- 모바일 주가 상세 → 관심 종목 변경 → 뒤로 이동, 태블릿 일정 다이얼로그와 소요 시간 선택 목록을 확인. 긴 메모 textarea의 중첩 스크롤이 끝까지 이동하고 별도 여백이 생기지 않음을 확인.
- 320×640 모바일, 768×1024 태블릿에서 콘텐츠 가로 넘침과 스크롤바 여백 없음 확인.
- `npm run build`, `npm run check`, `npm test` 통과. 총 144개 테스트 중 5개는 자동 영역 탐색·동적 추가·스타일 변경과 표시 길이·끝점·최소 크기·드래그 좌표 변환 검증.
- 캡처: `output/overlay-scrollbars/`.
