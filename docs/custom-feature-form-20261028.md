# 나만의 기능 만들기 입력 경험 개선 (2026-10-28)

## 기준

기존 모리의 색상, 입력창, 페이지 전환을 유지하면서 짧은 선택 목록과 작성 영역을 구분했다. design-taste-frontend의 기존 화면 점검 원칙을 적용했다.

Apple HIG의 [Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)에 있는 iPhone 캘린더의 반복 선택 사례를 확인했다. 짧고 서로 배타적인 옵션은 버튼 근처에 메뉴로 열고, 선택하면 값을 바꾼 뒤 닫는 방식을 참고했다. 다른 앱의 실제 동작을 확인한 것으로 확대 해석하지 않는다.

## 변경 사항

- 반복 선택은 폼 안에서 늘어나는 목록 대신 버튼에 연결된 팝업으로 표시한다. 화면 여유에 따라 위·아래 위치를 결정하며, 화면 밖으로 넘치지 않는다. 일정 종류 선택에도 같은 동작을 적용했다.
- 선택값의 체크 표시, 바깥 클릭, Escape, 방향키·Home·End·Enter, Tab 이동과 초점 복귀를 지원한다. Popover API를 사용할 수 없는 환경에는 고정 위치 메뉴를 제공한다.
- 참고 내용은 별도 입력 영역으로 묶었다. 펼침 상태, 입력 글자 수, 최대 6,000자 안내를 표시한다. 접어도 입력 내용은 유지한다.
- 카드 미리보기를 항상 보이도록 바꾸고 입력한 이름, 설명, 아이콘, 실행 주기를 즉시 반영한다. 긴 이름과 설명은 한 줄 말줄임으로 처리한다.
- 카드 아이콘을 기존 6종에서 18종으로 늘렸다. 기록과 정보 / 일정과 습관 / 생활과 이동 세 분류에서 선택한다. 기존 SVG 심벌과 선 굵기를 유지하며, 선택값은 저장·편집·실행 결과 목록·대시보드 표현까지 연결된다.
- 실행 시간 도움말은 해당 입력 바로 아래 한 곳에 표시한다. 반복을 먼저 선택한 경우와 맞지 않던 고정 안내 문구를 제거했다.

## 검증

- `npm run build`, `npm run check`, 전체 테스트 354개 통과.
- ego-browser에서 320×568, 390×844, 768×1024 화면과 밝은/어두운 테마를 확인했다. 가로 넘침이 없고, 반복 메뉴를 열기 전후 폼 높이와 스크롤 위치가 같았다.
- 메뉴 선택과 닫기, 키보드 조작, 참고 내용 접기 후 값 유지, 새 독서 아이콘으로 기능 저장 후 편집 복원을 확인했다.
- 미리보기 전용 저장소에서 검증했으며 테스트 데이터는 원래 값으로 복원했다.
- 실제 iOS Safari의 터치·가상 키보드·VoiceOver와 서버 저장 연동은 이번 검증 범위에 포함하지 않는다.
