# 일정 주 보기 정리 · 2026-10-27

사용자 스크린샷과 소스에서 주 보기의 날짜·상태·추가 동작 배치를 확인했다. 오른쪽의 큰 원형 + 버튼을 제거하고 16px 아이콘과 ‘추가’ 문구가 있는 투명한 보조 버튼으로 바꿨다. 실제 터치 영역은 최소 58×44px이다. 상태는 날짜 아래에 모아 날짜 선택 버튼의 설명으로 읽히게 했다. 선택 날짜는 aria-pressed로 전달한다.

빈 날짜는 ‘비워둔 하루’만 표시하고 반복되는 ‘등록된 일정이 없어요’ 문구를 제거했다. 일정이 있는 날과 없는 날 모두 같은 헤더 정렬을 사용한다. 태블릿에서 날짜를 별도 160px 열에 배치하던 규칙도 제거해 일정 카드가 목록 너비를 사용하게 했다. 날짜·시간은 고정폭 숫자를 사용한다. 호버·누름 상태는 기존 공통 색상과 타이밍을 사용하며 위치·크기를 움직이지 않는다.

이번 수정은 기존 날짜 부분 갱신·월/주/일 접힘 동작·상세 카드 확대를 유지한다. 추가 버튼은 해당 날짜를 기존 일정 작성 폼에 전달한다. 긴 일정명과 장소의 기존 말줄임 처리는 유지한다.

검증: SCSS 빌드, 구문 검사, diff 공백 검사 통과. 일정 렌더링·날짜 선택·이동·부분 갱신·모션 관련 기존 테스트 90개 통과. 5173 서버가 127.0.0.1에서 수신 중임을 확인했다.

ego-browser 2.1.0 가이드 전체를 읽었다. 이전 도구의 명시적 localhost origin 접근 거부가 해제됐다는 확인이 없어 브라우저에 재접속하거나 다른 경로로 우회하지 않았다. 실제 화면의 크기별 배치·터치·전환 체감 검증은 미완료다.
