# 카드 상세 내부 UI 통일 · 2026-10-27

사용자가 유지하려는 동작은 ‘지금 챙길 것’ 카드가 확대되어 상세 화면이 되고, 닫으면 원래 카드로 돌아오는 전환이다. 직전의 공통 가로 탐색으로 바꾸는 수정은 잘못된 해석이어서 원복했다. 카드 요약·확대/복귀 애니메이션·닫기 방식은 복원했다.

내부 불일치의 원인은 공통 본문 스타일이 `data-sheet-surface="sheet"`만 대상으로 하여 카드 상세(`card`)를 제외한 점이었다. 또 상세 내부 탭에는 전역 탭과 다른 크기·간격의 규칙이 남아 있었다.

수정 범위는 다음과 같다.

- 카드 상세 본문에도 공통 버튼·목록·입력·도움말·상태 표시의 스타일을 적용한다. 외부 프레임이나 요약 카드의 구조에는 공통 시트 프레임을 적용하지 않는다.
- 상세 내부의 별도 탭 스타일을 제거하여 앱의 전역 segmented 스타일을 그대로 사용한다.
- 본문 읽기 폭은 760px, 좌우 여백은 공통 페이지와 같은 20~32px로 맞춘다. 본문 배경·목록 표면·버튼 간격을 같은 색상 토큰과 규칙으로 맞춘다.
- 카드 본문에도 공통 호버·눌림·포커스·동작 줄이기 처리를 적용한다.

검증:

- 실제 `openSheet()`에서 대시보드·예정 카드의 확대 표면 및 카드 요약이 유지되고, 기능 목록의 일반 페이지 탐색이 유지되는지 확인했다.
- 편집 화면은 공통 편집 헤더를 사용하고, `backSheet()` 실행 후 확대된 카드 상세와 스크롤 124px을 복원하는지 확인했다.
- 기존 확대/복귀·중단·포커스 복원·동작 줄이기·탐색 이력 회귀 검사를 통과했다.
- `npm run check`, `npm run build`, 전체 테스트 **325개**, `git diff --check` 통과.

위 검증은 실제 앱 함수·자동 회귀 검사에 기반한다. 저장된 브라우저 접근 거부가 해제됐다는 새 확인이 없어 브라우저에 다시 접근하지 않았으며, 변경 후 화면의 시각적 재검증은 미완료다.
