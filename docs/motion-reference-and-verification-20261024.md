# 모리 모션 레퍼런스와 완료 검증

2026-10-24 · HEAD `0d9874a` 위의 현재 작업 트리 기준

**최신 상태:** 사용자가 브라우저 접근 설정을 변경한 뒤 ego-browser로 `http://localhost:5173/` 실제 화면을 검증했다. 달력의 CSP 적용 누락과 빠른 역전환 시 선택 날짜 잘림을 수정했고, 전체 자동 검사 323개를 통과했다. 아래 차단 기록은 권한 변경 전의 이력이며 현재 상태는 문서 마지막의 실제 화면 검증 결과를 따른다.

사용자 목표는 여러 앱, 특히 Apple 앱을 참고해 모리의 탭 전환을 더 풍부하고 자연스럽게 만들고 UI/UX도 함께 개선하는 것이다. 이후 합의한 조건은 푸터의 순차 진입, 기능 필터의 카드 전환, 깜빡이지 않는 월·주·일 연결, 입력·스크롤 보존이다. 현재 효과를 다시 임의로 바꾸는 대신 공식 사례와 구현·테스트를 대조했다.

## 권한 변경 전 실제 화면 검증의 차단 기록

브라우저 목록에는 이전 localhost 연결 거부 오류 탭이 남아 있었다. 같은 `http://localhost:4173/`를 허용된 HTTP 주소로 직접 열자 브라우저 도구가 저장된 사용자 권한 또는 관리 정책에 의한 origin 접근 거부를 반환했다. 이 반환이 현재 도구 접근의 직접 근거다. 서버 시작 재시도는 `Port 4173 is in use`로 종료됐으므로 새 서버가 시작됐다고 보고하지 않는다.

다른 브라우저, 포트·호스트 변경, 직접 자동화, 터미널에서 화면 캡처 등으로 제한을 우회하지 않았다. 접근 설정이 바뀌면 동일 주소의 실제 페이지에서 다음을 검증해야 한다.

1. 320·390·768px 및 넓은 화면에서 푸터 다섯 탭 순환과 빠른 역전환: 겹친 배경·잘림·빈 프레임·잔여 레이어 없음.
2. 일정 월→주→일→월과 빠른 반전, 월 경계 이동: 날짜 연속성과 일정 패널의 이동, 선택 주의 실제 노출.
3. 접힘 중 화면 회전·반응형 경계 통과: 날짜 잘림 없음, 푸터 선택 배경 정렬 유지.
4. 기능 필터 순환, 빈 결과, 연속 대화·보관함 검색과 한글 조합 중 갱신: 입력·캐럿·결과 읽기 유지.
5. 라이트·다크 및 동작 줄이기: 대비·포커스 표시·조작 가능성 유지. 설정과 검증용 입력은 확인 전 상태로 복원.

따라서 목표 전체는 아직 완료로 판정하지 않는다. 남은 다음 단계는 실제 페이지 접근과 위 화면 검증이며, 추가 효과를 임의로 덧붙이는 작업으로 이를 대신하지 않는다.

## 사용자 지정 ego-browser 추가 확인 · 2026-10-24

사용자가 ego-browser를 명시적으로 지정한 뒤 설치된 스킬과 CLI 사용 지침을 읽고 같은 브라우저 작업 공간 `mori-motion-qa-20261024`(ID 1)에서 공개 인터넷 자료를 확인했다. 앱 소스와 모션 값은 변경하지 않았다.

- Apple 공식 영상은 ego-browser에서 로드·탐색·프레임 캡처가 가능했다. [75.5초 선택 컨트롤](../output/ego-motion-qa-20261024/apple-segmented-control.png), [322초 TV](../output/ego-motion-qa-20261024/apple-tv-tabbar.png), [339초 Music](../output/ego-motion-qa-20261024/apple-music-tabbar.png), [348초 Music](../output/ego-motion-qa-20261024/apple-music-348.png), [1093초 Maps](../output/ego-motion-qa-20261024/apple-maps-controls.png)을 직접 열어 관찰했다. Music의 두 장면에서 콘텐츠가 스크롤되어도 하단 탐색·재생 컨트롤이 유지되는 구조, 선택 컨트롤의 독립된 선택 표면, Maps의 콘텐츠와 조작 영역 분리를 확인했다. [원본 영상](https://developer.apple.com/videos/play/wwdc2025/323/).
- [토스 공개 글](https://toss.tech/article/interaction)을 ego-browser에서 열어 제목·본문 구조·시각 자료 로드를 확인했다. [페이지 캡처](../output/ego-motion-qa-20261024/toss-interaction-reference.png).
- [NAVER 공개 예제](https://naver.github.io/egjs-flicking/ko/docs/demos/basic/interruptable)에서 `interruptable` 옵션 설명과 두 비교 패널이 렌더링된 것을 확인했다. [페이지 캡처](../output/ego-motion-qa-20261024/naver-interruption-reference.png). 이 확인은 NAVER 라이브러리 예제에 한정되며, 네이버 앱 탭 전환을 직접 조작한 결과가 아니다.

이 캡처는 공식 영상의 특정 시점과 공개 페이지를 관찰한 증거다. Apple 앱을 실제 기기에서 조작하거나 전환의 프레임 속도·소요 시간을 측정한 결과는 아니다. 기존 모리의 520ms 순차 진입·460ms 필터 진입·420ms 달력 연결 값을 Apple에서 측정한 값으로 재해석하지 않는다.

접근 상태는 두 가지로 구분된다. 공개 인터넷 페이지는 ego-browser로 확인할 수 있다. 그러나 localhost 검증은 여전히 미완료다. 기본 샌드박스의 CLI 연결은 `Failed to connect to ego_cli bootstrap`으로 종료됐고, 연결 가능한 환경에서 localhost 검증을 실행하려던 요청은 자동 승인 검토가 기존 브라우저 보안 차단의 우회에 해당한다는 이유로 거절했다. 이후 실행한 스크립트는 공개 Apple·토스·NAVER 주소만 사용했다. localhost 재접근, 다른 포트·호스트나 로컬 화면 복제를 시도하지 않았다.

앱 코드가 달라지지 않아 이전 자동 검사 322개를 반복 실행하지 않았다. 위 관찰은 레퍼런스 확인 범위를 보완하지만 모리의 실제 화면 검증을 대신하지 않는다.

## 권한 변경 후 실제 화면 검증 · 2026-10-24

사용자가 접근 설정 변경을 확인한 뒤 같은 ego-browser 작업 공간(ID 1)에서 localhost:5173을 열었다. 푸터 다섯 탭, 월·주·일, 모든 기능·기본 기능·내 기능을 직접 조작하고 `requestAnimationFrame`, DOM identity, 계산된 스타일, Web Animations 상태와 화면 캡처를 함께 확인했다.

실제 화면에서 발견한 두 문제를 수정했다.

1. **월·주·일이 접히지 않던 문제:** CSP가 HTML 인라인 스타일을 차단하여 템플릿의 CSS 변수 값이 비어 있었다. 달력 행 수·선택 주를 의미 있는 `data-*` 속성으로 전달하고 외부 CSS에서 적용한다. 보안 정책은 유지했다. 수정 전 주 보기에서도 월 높이 316px이 유지됐지만 수정 후 60px로 접혔다.
2. **빠른 역전환 시 선택 날짜 잘림:** 높이와 격자 이동을 별도 CSS 전환으로 처리하면 중간 반전 시 진행률이 달라졌다. 하나의 등록된 CSS 숫자 속성 `--calendar-fold`가 두 값을 함께 계산하도록 바꿨다. 320·390px 연속 왕복에서 선택 날짜 잘림을 재현한 뒤, 수정 후 같은 동작에서 잘림이 사라지는 것을 확인했다. 리사이즈 정리 경로도 공유 진행률을 완료한다.
