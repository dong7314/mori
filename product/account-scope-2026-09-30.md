# 마이 화면 범위와 계정 정책

기준일: 2026-09-30. 사용자의 최신 요청을 반영하며, 이전 시나리오의 복잡한 개인화 설정보다 이 범위를 우선한다.

마이는 **로그인·로그아웃, 사용자 정보와 이름 수정, 테마, 무료·Pro 요금제 안내와 결제 관리**만 다룬다. 기능의 수행 조건은 해당 기능 상세에서 관리한다.

| 항목 | 현재 동작 | 남은 작업 |
| --- | --- | --- |
| 로그인·로그아웃 | 네이버·카카오 소셜 인증, 서버 세션 프록시 | 운영 소셜 키와 콜백으로 실제 왕복 검증 |
| 사용자 정보 | 이름·소셜 제공자·가입일·서버가 판단한 등급 조회 | 실제 계정 화면 인수 확인 |
| 이름 수정 | 이름만 PATCH, revision 충돌 처리, 재로그인 후 보존 | 다른 기기에서 편집 충돌 UI 확인 |
| 테마 | 시스템·라이트·다크; 비로그인 기기 저장, 로그인 계정 저장 | 실제 앱의 시스템 테마 연동 |
| 무료 | 0원, 결제 불필요 | 기능/사용량 한도 정책 확정 |
| Pro | 현재는 최고 관리자 승인 권한 표시 | 가격·주기·결제 제공자·기존 승인 Pro 전환 정책 |
| 결제·취소 | 준비 중 안내, 동작 버튼 비활성 | 검증된 결제 처리·webhook·구독/해지 API |

무료 선택을 결제 거래로 만들지 않는다. 관리자 승인 Pro는 유료 구독과 다르며, 결제 취소로 승인 권한까지 자동 회수하지 않는다. 결제 완료·해지 완료를 흉내 내는 기능은 제공하지 않는다.

마이에서 제거한 항목은 대시보드 기록 수, 최근 대화 표시 토글, 출근 시간, 카드 표시 간격, 체험 시간 변경, 데이터 초기화, 가짜 Free/Pro 전환이다. `/v1/me/preferences`와 `/v1/me/summary`도 공개 계약에서 제거했다. 출근 습관 등 기존 내부 비서 문맥 데이터는 보존하되 사용자 계정 설정으로 노출하지 않는다. 신규 문맥 학습/적용은 후속 개발이다.

대시보드의 시간 범위 버튼(지금·3시간·5시간·하루)은 화면 탐색 기능이므로 유지한다. 범위를 바꿔도 현재 시각이나 예약은 바뀌지 않는다. 대시보드 상단의 별도 하루 체험 진입은 PoC 시연 기능으로 남아 있으며 제품 마이 설정에 포함하지 않는다.
